# Calculator — GitHub Practice

## About This Project

This is my first project created to learn and practise Git and GitHub.

The goal was to become familiar with version control and understand how developers manage projects using Git and GitHub. Rather than learning commands in isolation, I wanted to apply them to a small, practical project.

I chose to build a calculator with a user interface. The calculator itself was developed using AI-assisted coding, as the main focus of this project was learning the Git and GitHub workflow rather than writing the application code from scratch.

## What I Practised

Throughout this project, I gained hands-on experience with:

- **Repositories:** Creating and managing a GitHub repository.
- **Commits:** Tracking changes and maintaining a history of development.
- **Branches:** Creating and switching between branches to work on different features.
- **Merging:** Integrating changes from feature branches into the main branch.
- **Push and Pull:** Synchronizing changes between my local repository and GitHub.
- **Pull Requests:** Practising the process of proposing and merging changes.
- **Git History:** Reviewing commits to understand how a project evolves over time.

## Tools Used

- Git
- GitHub
- Visual Studio Code
- AI-assisted coding

## About the Calculator

The calculator serves as a practical project for experimenting with Git and GitHub. It includes a web interface and scientific calculator functionality.

The application is not the primary focus of this repository; it provides a hands-on environment in which to practise version control.

## Key Takeaway

This project helped me move beyond simply creating a GitHub account and start understanding how Git and GitHub can be used to manage a project throughout its development.

My goal was to learn by doing, make mistakes, understand the workflow, and become more comfortable using version control.

This is the beginning of my journey with Git and GitHub, and I plan to build more projects as I continue learning.
